# Сон Mac — строка меню

Приложение для управления системным сном Mac через строку меню.
macOS 13+, универсальная сборка для Apple Silicon и Intel.

## Установка и использование

Соберите приложение, перенесите `Sleep Toggle Menu.app` в «Программы» и откройте.
Автозапуск не устанавливается.

В строке меню только маленький значок без текста: `zzz` (системный сон разрешён) или чашка
(системный сон запрещён). Нажмите значок и выберите «Не давать Mac засыпать».
Состояние также видно во всплывающей подсказке. У приложения есть иконка для Finder.
При запуске приложение только читает состояние. Оно обновляется каждые 20 секунд и при
открытии меню. Если состояние прочитать нельзя, переключатель недоступен.

Для изменения выполняется ровно `/usr/bin/sudo -n /usr/bin/pmset -a disablesleep 0` или `1`.
Если разрешение уже настроено, оно используется сразу.
Иначе предлагается однократная настройка с системным запросом пароля администратора.
После неё переключение и выход работают без пароля. Пароль не читается и не хранится.
При отмене настройки переключение отменяется.

Установщик создаёт постоянное правило sudoers для двух точных команд от имени root,
без подстановок и произвольных аргументов. Правило доступно всем программам пользователя,
не только этой утилите. Файл `/private/etc/sudoers.d/sleep-toggle-menu-<числовой UID>`
проверяется через visudo, получает права root:wheel/0440 и устанавливается атомарно.
Существующие правила sudoers не изменяются. Удаление приложения не отзывает права:
для отзыва администратору нужно удалить именно этот файл. При сборке и диагностике
правила не устанавливаются.

Значок `zzz` означает отсутствие запрета disablesleep, а не гарантию немедленного сна:
Mac могут удерживать другие процессы. Таймер дисплея не меняется. Поведение при закрытой
крышке зависит также от macOS и оборудования. Не кладите работающий Mac в сумку.

При обычном выходе через «Выйти и разрешить сон» приложение автоматически выполняет
восстановление сна, если сон был запрещён (или состояние прочитать не удалось).
После первоначальной настройки это происходит без пароля. При ошибке восстановления приложение
остаётся открытым. Если сон уже разрешён, выход выполняется сразу без изменения настроек.
Принудительное завершение, сбой, отключение питания или принудительное завершение сеанса
могут обойти этот обработчик: системный параметр сохраняется, в том числе после перезагрузки.
Для ручного восстановления: `sudo pmset -a disablesleep 0`.

В приложении нет сетевого кода, телеметрии, фонового сервиса или установки автозапуска.
Сборка локально подписана ad-hoc, без сертификата Developer ID и нотарификации Apple.
Это не сертификат безопасности; весь исходный код находится рядом для проверки.

## Сборка и проверки

Нужны Apple Command Line Tools. Выполните `bash build.sh` из этой папки.
Сборка создаёт универсальный `.app`, ZIP и PNG-превью иконки в родительской папке.
Иконка — векторный рисунок AppKit, преобразованный в ICNS системным iconutil.

Исполняемый файл поддерживает диагностические аргументы:

- `--self-test`: тесты разбора вывода и точных команд, без изменения системы.
- `--read-state`: чтение реального состояния через `pmset -g`.
- `--check-permissions`: проверка списка разрешённых команд без выполнения.
- `--verify-current-state`: реальный вызов sudo без пароля с текущим значением параметра,
  повторно применяет его без изменения состояния сна; не устанавливает разрешений.
- `--smoke-test`: краткий запуск интерфейса, проверка значка/меню и выход без изменения сна.

Системные механизмы интерфейса: [NSStatusBar](https://developer.apple.com/documentation/appkit/nsstatusbar)
и [LSUIElement](https://developer.apple.com/documentation/bundleresources/information-property-list/lsuielement).
